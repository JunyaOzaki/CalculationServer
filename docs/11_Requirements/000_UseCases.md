# Use Cases

- 外部アプリから指定したシート・セル値を書き換える
- 外部アプリから指定したシート・セル値に対して、演算処理を更新しその結果を取得する
- 名前付きセルを更新する
- レシピを切り替える
- Workbookを保存する
- Workbookを読み込む
- 計算エラーを取得する
- 依存セルを自動更新する
- 外部アプリへ変更通知する
- プラグイン関数を呼び出す
- UI上で現在のセル情報を表示する
- UI上で値を書き換えをする
- UI上で値のコピー＆ペースト（値のみ・形式ごと）をする
- 複数の外部アプリから同じWorkbookのデータ操作をする
- 外部アプリから複数のWorkbookのデータ操作をする
