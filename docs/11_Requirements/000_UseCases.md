# Use Cases

## UI関連
- Workbookファイルを開く
- Workbookファイルに保存する
- 新規作成で、空のシート（１つ）のWorkbookを生成する
- UI上で現在のセル情報を表示する(数式の場合は、数式の結果を表示)
- UI上で値を書き換えをする
- UI上で値のコピー＆ペースト（値のみ（形式指定）・セルごと）をする
- セルの最大行・最大列は、Excel同等とする
- グラフ機能は実装しない
- 書式設定する機能は実装しない（ただし、保存されている罫線・背景色を表示は表示させたい）
- セル検索機能（数式・値）

## セル操作関連
- 外部アプリから指定したシート・セル値を書き換える
- 外部アプリから指定したシート・セル値に対して、演算処理を更新しその結果を取得する
- 名前付きセルを更新する
- レシピを切り替える
- 計算エラーを取得する
- 依存セルを自動更新する
- プラグイン関数を呼び出す
- 使用できるワークシート関数を利用できる（利用不可な関数は提示する）

## 外部連携関連
- 外部アプリへ変更通知する
- 複数の外部アプリから同じWorkbookのデータ操作をする
- 外部アプリから複数のWorkbookのデータ操作をする
- 外部アプリから、UI側操作の有効・無効を設定/状態取得を出来るようにする
